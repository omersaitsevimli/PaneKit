# Shortcuts

Base chord: **Control + Option** (`⌃⌥`). Remap or disable any binding in **Settings → Shortcuts**.

## Layouts & general

| Shortcut | Action |
| --- | --- |
| `⌃⌥L` | Layouts picker |
| `⌃⌥↩` | Maximize (fills work area; ignores window gap) |
| `⌃⌥=` | Almost maximize |
| `⌃⌥⇧↑` | Maximize height |
| `⌃⌥-` / `⌃⌥⇧=` | Smaller / Larger |
| `⌃⌥C` | Center (keep size) |
| `⌃⌥⌫` | Restore pre-snap frame |

## Halves & quarters

| Shortcut | Action |
| --- | --- |
| `⌃⌥←` `→` `↑` `↓` | Halves |
| `⌃⌥U` `I` `J` `K` | Quarters |

## Thirds / two-thirds

| Shortcut | Action |
| --- | --- |
| `⌃⌥D` `F` `G` | Left / center / right third |
| `⌃⌥E` `R` `T` | Left / center / right two-thirds |

## Fourths & sixths

| Shortcut | Action |
| --- | --- |
| `⌃⌥A` `S` `Z` `X` | Horizontal fourths |
| `⌃⌥Q` `W` `O` · `;` `'` `/` | 2×3 sixths |

Wider fourth spans are **size-cycle only** by default (press the same fourth shortcut again).

## Multi-window

| Shortcut | Action |
| --- | --- |
| `⌃⌥,` / `⌃⌥.` | Tile rows / columns |
| `⌃⌥]` / `⌃⌥[` | Cycle stacked windows |

## Display / workspace / stash

| Shortcut | Action |
| --- | --- |
| `⌃⌥⌘←` / `→` | Previous / next display |
| `⌃⌥P` | Restore last workspace |
| `⌃⌥`` / `⌃⌥⇧`` | Stash toggle / unstash all |

## Size cycle

Pressing the **same** snap shortcut again advances the size family, then (if available) moves to the adjacent display — Rectangle-style.
