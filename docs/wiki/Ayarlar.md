# Ayarlar

Menü çubuğu → **Settings… / Ayarlar…**

## General

| Ayar | Açıklama |
| --- | --- |
| **Açılışta başlat / Launch at Login** | Girişte PaneKit’i aç (menüde de var) |
| **Drag-to-snap** | Kenara sürükleyerek snap |
| **Kenar sürükle (split resize)** | Ortak kenardan iki pencereyi boyutlandır |
| **Yeşil düğme + ⌥ → Layouts** | Zoom düğmesinde Option ile Layouts |
| **Stage Manager şeridi için yer bırak** | Stage Manager açıkken soldan inset |
| **Ekran bağlanınca workspace yükle** | Harici ekran takılınca son/seçili workspace |
| **Neredeyse tam kenar boşluğu** | Almost-maximize inset (10–60 px) |
| **Pencere boşluğu / Window gap** | Karolar arası boşluk (0–16 px) |
| **Pin şerit genişliği** | 300 / 400 / 500 px |

## Shortcuts

Her snap aksiyonu için:

1. Kutuya tıkla  
2. Yeni kısayolu bas  
3. **Reset** → varsayılan  
4. ✕ → kısayolu kapat  

`⌃⌥A` (1. çeyrek) geçerlidir — `A` tuşunun key code’u 0 olsa da kayıtlıdır.

## Menü çubuğundan hızlı ayarlar

Settings’e girmeden:

- Snap zone kalınlığı  
- Almost-max inset  
- Window gap  
- Drag-to-snap / shared edge / yeşil düğme aç-kapa  
- Pin Mode  
- Launch at Login
