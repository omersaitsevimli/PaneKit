## Hızlı başlangıç / Quick start

1. [Releases](https://github.com/omersaitsevimli/PaneKit/releases/latest) → `PaneKit-*-macos-arm64.zip` indir  
2. `PaneKit.app` → `~/Applications/`  
3. Sağ tık → **Aç**  
4. **Erişilebilirlik** iznini yalnızca bu kopyaya ver  
5. Menü çubuğundaki PaneKit ikonundan veya `⌃⌥←` ile dene  

Detay: [Başlangıç & Kurulum](Başlangıç-ve-Kurulum) · [Getting Started](Getting-Started)

## Ne yapar? / What it does

- **Snap** — yarı / çeyrek / üçte bir / fourths / sixths, maximize, ortala, geri al  
- **Tekrarlayan kısayol** — aynı tuşa tekrar: boyut döngüsü, sonra diğer monitör  
- **Layouts** — Windows tarzı şablon + sürükle-bırak (`⌃⌥L`)  
- **Drag-to-edge** — dar magnet alanı; ortak kenardan iki pencereyi birlikte boyutlandır  
- **Tile** — tüm pencereleri satır / sütun ızgarasına diz  
- **Pin** — bir uygulamayı sağ şeritte sabitle  
- **Workspaces** — düzeni kaydet / yükle  
- **Stash** — pencereyi kenara gizle, şeride gelince geri aç
