# Kısayollar

Taban akort: **Control + Option** (`⌃⌥`). Hepsi **Settings → Shortcuts** üzerinden değiştirilebilir veya kapatılabilir.

## Layouts & genel

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥L` | Layouts şablon seçici |
| `⌃⌥↩` | Maximize (work area’yı doldur; gap yok sayılır) |
| `⌃⌥=` | Neredeyse tam (kenar boşluğu ayarlanabilir) |
| `⌃⌥⇧↑` | Yüksekliği maksimize (genişlik aynı) |
| `⌃⌥-` | Küçült (ortadan) |
| `⌃⌥⇧=` | Büyüt |
| `⌃⌥C` | Ortala (boyutu koru) |
| `⌃⌥⌫` | Snap öncesi boyuta dön (restore) |

## Yarılar & çeyrekler

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥←` `→` `↑` `↓` | Sol / sağ / üst / alt yarı |
| `⌃⌥U` `I` `J` `K` | Sol üst / sağ üst / sol alt / sağ alt çeyrek |

## Üçte birler

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥D` `F` `G` | Sol / orta / sağ üçte bir |
| `⌃⌥E` `R` `T` | Sol ⅔ / orta ⅔ / sağ ⅔ |

## Fourths & sixths

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥A` `S` `Z` `X` | 1. / 2. / 3. / 4. çeyrek (yatay) |
| `⌃⌥Q` `W` `O` | Üst sıra sixths (sol / orta / sağ) |
| `⌃⌥;` `'` `/` | Alt sıra sixths |

> Daha geniş fourth span’leri (iki/üç çeyrek) varsayılan olarak ayrı kısayola bağlı değildir; **aynı fourth kısayoluna tekrar basınca** boyut döngüsünde gelir.

## Çoklu pencere

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥,` | Tüm pencereleri satırlara diz |
| `⌃⌥.` | Tüm pencereleri sütunlara diz |
| `⌃⌥]` / `⌃⌥[` | Aynı konumdaki yığın pencereleri çevir |

## Monitör, workspace, stash

| Kısayol | İşlem |
| --- | --- |
| `⌃⌥⌘←` / `→` | Önceki / sonraki ekran |
| `⌃⌥P` | Son workspace’i yükle |
| `⌃⌥`` | Odak penceresini stash / geri al |
| `⌃⌥⇧`` | Tüm stash’leri aç |

## Tekrarlayan kısayol (size cycle)

Aynı snap kısayoluna **tekrar** basınca:

1. Aile içindeki bir sonraki boyut (ör. sol yarı → sol ⅔ → sol ⅓)  
2. Aile bitince (çoklu monitörde) **yan ekrana** taşı  

Bu Rectangle tarzı davranıştır; bozulma değildir.

## Özelleştirme

1. Menü → **Settings… / Ayarlar…** → **Shortcuts**  
2. Satıra tıkla → yeni kısayolu yaz  
3. **Reset** ile varsayılana dön  
4. ✕ ile kısayolu kapat  

Çakışma varsa uyarı çıkar.
