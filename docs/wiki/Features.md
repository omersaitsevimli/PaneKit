# Features

## Snap

Keyboard / menu placement into the work area: halves, quarters, thirds, fourths, sixths, maximize, almost-maximize, center, restore. Repeat the same shortcut to **size-cycle**, then move to the next display.

## Drag-to-edge

Title-bar drag into a narrow magnet zone (~6 px by default). Configurable or disable from the menu.

## Shared-edge resize

Drag the seam between two touching windows to grow one and shrink the other. Respects window gap.

## Tile & stack

- `⌃⌥,` / `⌃⌥.` — tile all windows in rows / columns  
- `⌃⌥]` / `⌃⌥[` — cycle stacked windows at the same spot  

Pin and stashed windows are skipped where appropriate.

## Pin Mode

Keep one app in a right sidebar on the primary display; other snaps use the remaining work area. Set pin app from the menu, then enable Pin Mode.

## Workspaces

Save / restore window frames. Optional restore when a display connects. `⌃⌥P` restores the last workspace.

## Stash

Slide a window mostly off-screen; hover the peek strip to reveal. `⌃⌥`` toggles; `⌃⌥⇧`` unstashes all.

## Work area

`visibleFrame` − Stage Manager strip − Pin sidebar, then per-tile window gap. Maximize ignores gap.
